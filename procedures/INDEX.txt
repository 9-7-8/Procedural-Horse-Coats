PROCEDURES - INDEX
==================

Every repeatable routine in this project is a plain-text file in this folder. The format
is in FORMAT.txt. Each file is also a slash command: .claude/skills/<slug>/SKILL.md is a
thin wrapper that says "read procedures/<slug>.txt and follow it", and holds no steps of
its own. /show-procedures prints this list.

When the owner says one of the SAY words below, read that file in full and follow it.
Do not work from memory of what the routine says: the file is the only copy.

How they fit together
---------------------
  feature wanted -> write-intake-document -> intake/ treatment -> process-intake -> end-session
  bug or tuning  -> report-bug (cloud), run-tests (yard) or review-server-logs (server)
                    -> GitHub issue (bug | tuning) -> fix-bug -> end-session
  needs her eyes -> hand-over-a-test -> launch-game
  any change     -> rebake -> test-tiers (lowest tier that proves it)
  shipping       -> release: offer -> owner decides -> the release set -> tag + jar + note

Routines that might become procedures next
------------------------------------------
They are queued in intake/To do.txt, under "Routines to write up as procedures". When one
is written, by FORMAT.txt, its bullet is deleted there and its row added above.
