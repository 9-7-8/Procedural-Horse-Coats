Test

The diagnostic gene. A dominant T paints a two-axis gradient flat on top of the resolved coat — pink→blue along body X, red→yellow along body Y — so the full colourful field is visible on any base. It exercises the projection engine end to end, and it is the only gene that uses flat paint.

It is deliberately common (1 in 4 carriers) while the skin engine is being built, and expect it removed once the engine is trusted. Its wild frequency and its place in the registry are not a model of anything.

Flat paint, and why it is allowed here

Every other magical gene should add to the colour accumulator, which is what keeps phase 3 order-independent. Test uses ColorField.set instead — flat, opaque paint that replaces the accumulator:

common/genetics/genes/TestGene.java
@Override
public ColorField tint(AllelePair pair, CoatBuildContext ctx,
                       PigmentView coat, ColorView colour) {
    if (!isTest(pair)) {
        return null;
    }
    ColorField delta = ColorField.deltaLike(colour);
    TestCoatPattern pattern = new TestCoatPattern(HorseSkinGeometry.bodyBounds(ctx.skin()));
    HorseSkinGeometry.forEachTexel(ctx.skin(), (px, py, part, face, point) -> {
        int argb = pattern.argb(point.x(), point.y(), point.z());
        delta.set(px, py, argb >>> 24, (argb >> 16) & 0xFF,
                          (argb >> 8) & 0xFF, argb & 0xFF);
    });
    return delta;
}

Setting instead of adding is what makes the field read the same on any base — black, chestnut, or dominant white. A diagnostic gradient is only useful if it does not interact with pigment restriction, which is precisely what a diagnostic needs and precisely what an ordinary gene must not do.

The rule set comes with

set is reserved for COMPLETE_DOMINANT genes — genes that mask everything anyway — because a replace is order-dependent and erases every magical gene before it. That is exactly why Test is last in Genes.magicalOrder(): anything after it would show through its overlay, which would contradict its own dominance declaration.

The pattern

TestCoatPattern implements CoatPattern — a pure (x, y, z) → ARGB function in body space, normalised against bodyBounds(skin). Pink to blue along X (tail to nose), red to yellow along Y (hooves to topline).

Because it is a plain function of body-space position, it is the sharpest check there is on the projection engine: any seam, mis-scaled part or wrong face orientation shows up immediately as a discontinuity in a smooth gradient. That is its whole job.

Cache note

Test is deterministic, so a T_ horse would normally share one baked texture per genotype. But if the horse also carries a visible non-deterministic gene — bay, grey, splash, magic zebra — the genotype is still flagged non-deterministic, so it bakes a unique (and identical-looking) texture per horse. Harmless; a few extra cache entries.
