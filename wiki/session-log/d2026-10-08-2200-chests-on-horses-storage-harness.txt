----------------
1. #218 (filed): worn gear never dropped or returned. Partly fixed, see DONE 4.
2. A barrel, a shelf and a shulker box carry an EMPTY minecraft:container component by
   default. Stripping it on the way onto a horse would have handed back a barrel that never
   stacked again. Caught while writing the gametest, fixed before the first commit; the
   test pins it.
3. wiki/tools/bake-item-art.mjs copied layer0 only, so a layered, dyed item came out as its
   untinted base. It now composites layers with the default dye. (e5a6e311)

   box without its contents. GearView.getItem now shows the packed box and setItem drops the
   store's copy. Fixed before the first commit.
5. bake-config-keys.mjs cannot evaluate an expression as a default (4 * 27 * 64); the
   default is a literal with a comment.
6. Mistake: the first compile of this session ran before checking whether the owner's
   client was open. It was not. Every later launch checked first.
