DECIDED
-------
Calls made without the owner (none is a design call; all sit inside the treatment's
decided lines):
- The cooldown is kept in memory and not saved, so a restart forgets it. Recorded on
  horse-browser.html#send-home-free-built.
- The config validator accepts blank or any parseable id. Whether the id is a real item
  is checked at use time, so an unknown id is free with one warning (the treatment said
  "refused or logged and treated as free").
- The alternatives sentence names the Basic Ticket, Holding Pen Ticket and Ender
  Whistle, read from the live items.
- The button greys out on the client when a price is set and the pack is short. The
  client reads the price from the synced SERVER config rather than a payload (api-notes
  already records that SERVER config syncs to clients).
- The button no longer ticks off the USE_*_TICKET checklist tasks, since it spends no
  ticket. Using a ticket by hand still does.
