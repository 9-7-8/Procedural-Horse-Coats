Splash white

Random white markings, as if the horse were dipped in white from below: white climbs each leg an independent random amount, plus a random centreline blaze. It removes both pigments, so the white template shows through — the same mechanism dominant white uses, applied to a region.

What is implemented renders correctly — leg white plus a centreline blaze.

What it does

common/genetics/genes/SplashGene.java
Rng epi = ctx.epigeneticsFor(KEY);
PigmentField f = coat.mutableCopy();

for (var leg : CoatRegions.LEGS) {
    double h = 0.15 + epi.nextFloat() * epi.nextFloat() * 0.75;   // socks .. stockings
    CoatRegions.whitenLowerLeg(skin, f, leg, h);
}

double blazeHalfWidth = 0.4 + epi.nextFloat() * 1.4;   // body units either side of centre
double blazeLength    = 0.2 + epi.nextFloat() * 0.75;  // fraction of the head length
CoatRegions.whitenBlaze(skin, f, blazeHalfWidth, blazeLength);
return f;

Each leg is rolled independently (unlike bay, which rolls one extent for the horse and jitters around it), so a splash horse can have three socks and one stocking. The f*f product biases the distribution low: most splash horses have modest socks and a few have tall ones.

Three open gaps

1. It is not actually incomplete dominant

It is tagged INCOMPLETE_DOMINANT, but restrict never looks at how many Spl copies the horse carries — so Spl/spl and Spl/Spl render identically. A homozygote should give much larger markings: higher stockings, a wide blaze or bald face, body patches.

The catalogue already gives the heterozygote its own pen, so the fix is visible the moment it lands. Gallery pens #11 eeaa nSpl and #19 eeaa SplSpl are the side-by-side check.

2. The blaze is the only face marking

CoatRegions.whitenBlaze paints a centreline stripe on the muzzle and head. The rest of the family — star, snip, stripe, bald face — is not built.

3. Every sock ends in a perfect ring

CoatRegions.whitenLowerLeg cuts at a hard point.y() <= cutoff, so the top edge is a clean circle all the way round. Break it up — per-texel epigenetic jitter, or the smoothstep treatment BayCoat.fade already uses, which is why bay’s leg black dissolves and splash’s white does not.

All three are tracked on To be verified. Fixing the dose is the prerequisite for the rest of the real SW1–SW10 series making any sense.

Interactions

  • It runs last in naturalOrder(), after even dominant white. A splash marking is set absolutely to zero, so nothing later can dilute it back into existence.
  • Invisible on a dominant-white horse — there is nothing left to remove.
  • A magical gene can still paint over a splash marking, because magical genes run after all of this and a transparent texel can be given opacity. That is how zebra stripes cross a sock.

The real locus

This is essentially SW1 on MITF. The full picture is two multi-allele loci, not one: SW1/3/5/6/8/10 are on MITF, SW2/4/7/9 on PAX3. So today’s splash gene eventually becomes the MITF locus with seven alleles — and whitenLowerLeg’s hard cut is shared with a future sabino 1, so fixing it benefits both. See the gene backlog.
