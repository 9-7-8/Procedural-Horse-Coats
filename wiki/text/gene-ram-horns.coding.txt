Ram horns
(Magical gene / dominant, sex-limited allele / grows geometry, paints nothing)
One copy and the horse grows a pair of ram’s horns — on a mare or a stallion with Rh , on a stallion only with Rhm , the way most horned sheep breeds have horned rams and polled ewes. How big they are, how far they curl, how thick and what shade are written on the allele. The third grown part, after the unicorn horn and antlers , and built on the antler pattern.

Gene key horsegenetics.ram_horns Class RamHornsGene Priority 235 (magical band); only a code-order slot Family Grown parts Alleles Rh Rhm n , dominance Rh > Rhm > n Founders written as pairs: Rh/n 0.14%, Rhm/n 0.26%, n/n the rest Epigenome size (0–0.6, clamp 0–1), curl (0–1), girth (0.85–1.15), shade (0–1, clamp −1–1) Coat effect none — measured: no coat hash moved in either golden The antler pattern, again Asked for as “a ram horn that follows the same pattern” (owner, 2026-10-01), and the choices were put to the owner: inheritance like antlers, all four shapes, and a tip colour gene with hoofprints that match it. So it is the antlers page with different geometry: the sex gate in grows(genotype) rather than the expression, a foal gate in PartKind.showsOnFoal , two kinds ( RAM_HORN_RIGHT / LEFT ) at the same CROWN anchors, one mesh per side, and everything composed in GrownParts.of . No new layer, render-state field or config key. The epigenome, by cost size : the class is the mesh's size bucket ( RamHornSize , five classes; a bigger horn is more segments so a full curl stays smooth); the remainder is a uniform stretch. curl : one of RamHornGenerator.CURLS buckets, in the mesh key with the shape — how far round a curl turns, how far back a scimitar sweeps, or how much a corkscrew or a horizontal twist rolls per segment. girth and shade : a draw-time scale and colour. Shade is pale horn to black; with a coloured tip it is the base colour. Below 0 it runs on from pale horn to bare bone at −1 (the antler’s PALE_BONE ) — the part’s bone version . No wild horse rolls below 0; the skeleton breeds band it to −1–−0.95. Added 2026-10-02, with the clamp widened from 0–1, so no saved horse’s horn changed. Two-tone colour now runs along each branch A two-tone part is drawn a box at a time in the colour AttachedPart.tintAt gives that far along. That used to be the box's index over the box count, which is right for a chain and wrong for a four-horned ram, whose curled horn hangs off the upright one’s root and would have been coloured as if it continued it. PartModel.along(i) is now the box’s depth over its depth plus the longest run still below it — identical for a chain, and root-to-tip for each horn of a branched part.
