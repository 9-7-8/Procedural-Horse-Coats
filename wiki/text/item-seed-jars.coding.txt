Seed jars
(Item / breeding)
A jar that stores a stallion’s genetics so you can breed a mare with him later — from anywhere, and without him being there.

What the jar stores The jar stores a GenomeSample — a genotype and an epigenome frozen to code strings — in a stored_genome data component, and the allele draw happens at conception , exactly as for every other pregnancy. StallionSeedJarHandler checks ReproHandler.receptive and calls ReproHandler.breed with the mare’s live genome, the jar’s stored one, and the jar’s carrot_effects as the sire’s. There is no second breeding code path. Filling calls ReproHandler.recordCover and disarm on the stallion. Full flow on fertility & gestation . Known gaps The synthetic sire record still uses the stored UUID as its pedigree edge, and its generation is 0; see the roadmap tab . Verified Collection and the tooltip work (owner-confirmed 2026-09-02). The first test that day found the held jar never changed in creative, because the result went to another slot; the jar now transforms in the player’s hand, creative included. The genome string the tooltip showed omitted the data-driven genes, a GeneCodeDisplay display bug rather than bad stored data, fixed 2026-09-03 and not re-checked. The breeding-mode gate and impregnation are unverified ( the verification tab ).
