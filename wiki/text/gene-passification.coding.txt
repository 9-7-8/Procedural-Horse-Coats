Passification
(Magical gene / no coat effect)
The way in to a horse that would otherwise kill you. It adds no aggression of its own — it says what you can offer the animal to make it stop, and while the bargain holds it will not target you for any reason.

Gene key horsegenetics.passification Alleles Prm , Tmp , FPr , APr , FTm , ATm , n Inheritance incomplete dominant — one copy expresses, and a compound heterozygote expresses both Epigenetics offering (a category index), amount , duration , cooldown Reaches the game as no effect verb — see below Coat effect none, ever The veto has to be asked at every chokepoint, not unpicked afterwards “Will not select the player as a target for any reason ” only means something if each reason asks. Passification.suppresses is consulted in five places: the temper verb's attacking mood, GeneAbilityHandler.flee (the same verb's fleeing mood), HorseAggroHandler.aggro (hit-it-and-its-herd), HerdGoals (a dam defending her foal) and GeneReactionHandler (guardian's retaliation). A gene added later that targets a player and does not ask here is a bug in that gene. flee was the fifth, and it was missing for eight days after this box was written promising there were no more — the box was right about the principle and wrong about the count, which is the failure mode it exists to warn about. It went unnoticed because no breed pinned a skittish allele until the Nightmare did, so no horse had ever been both calmable and frightened at once. A flee is a path already issued, so the veto alone does not stop one The other four chokepoints guard a target , which is re-read every tick, so dropping it is enough. flee issues a moveTo FLEE_DISTANCE blocks away and only re-picks on the temper beat, so a horse calmed mid-flight would run the leg out and only then turn round. Passification.forget therefore calls GeneAbilityHandler.stopFleeingFrom , which drops the FLEEING entry only when it is keyed to that player — a horse running from two people is still running from the other one and re-picks it on the next beat. flee 's own no-candidate path stops the navigation too, but likewise only when it was the thing that started it: stopping unconditionally every beat would cut the legs off whatever goal has the navigation instead, FoodTemptGoal walking a calmed horse back over most of all. The item is an index, so the table may only grow at the end The epigenome stores numbers, so “the item this horse wants” can only ever be a position in a list the gene owns ( PassificationGene.OFFERINGS ). Appending is the only safe edit. Re-ordering it silently changes what every existing horse in every save is asking for , and nothing will tell you. Appending is safe , not free . The schema is EpiValue.category(ITEM, OFFERINGS.size()) and EpiRoll rolls rng.nextInt((int) v.max()) , so the length of the list is the width of the wild roll: every entry added is an entry wild founders start asking for. The Netherhorse's own file claimed the opposite when it added two — that “every wild horse still only ever rolls the first twelve entries” — which was wrong, and is the reason a breed that only wants a band on itself still has to think about the whole population. PotionMilkGene has the same shape by a different route: it spreads a fixed WILD_CARRIER_PERCENT across however many brews exist, so appending dilutes every existing one. Why it is not an effect verb It would have been a verb with exactly one user, which is the same test lycanthropy and sun sensitivity failed. So the gene owns the genetics and the numbers and exposes one pure function, routesOf ; the NeoForge module owns the feeding, the clock and the veto. It is also not a standing effect but a veto on somebody else's, which no verb in the set can express. “Extremely high priority” is not the priority number The locus is required to override every other aggression effect. A gene's priority() could not do that: for a gene that paints nothing the number is only a slot in the genotype code's layout. The override is enforced by where the check lives — at the moment a target is acquired, after whatever decided to acquire it. The number here is merely high enough that a reader sorting the registry finds it after the loci it talks over.
