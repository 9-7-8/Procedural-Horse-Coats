LYCAN — the werewolf locus
(Magical recessive / no coat effect)
A horse with two matching copies stops being a horse at nightfall . Not a horse wearing a wolf: a real wolf, which breeds with wolves, is tamed with bones, and is a horse again at dawn with the same name and the same pedigree. Every peaceful land animal in the game is a shape on this locus, and every one of them is recessive to the wild type and to each other.

Gene key horsegenetics.lycan Priority 152 — after rainbow dust ; a code-order slot only Alleles one per peaceful land animal + n — see the table Outcomes wild, carrier, mismatched, and one per shape Shows when two copies of the same allele Default allele n Wild frequency 0.03% per shape, whatever the shape count — no founder is a carrier Founder draws 1 × nextFloat() Coat effect none, ever Epigenetic one colour — the cloud the shifted animal trails Not play-tested, and the most invasive thing in the mod This gene discards a horse entity and creates a different one , twice a day. Written against 26.1.2 sources and never watched happen. The things to check first are on the verification tab , and the top of that list is: does a shifted horse come back with its name, its record and its pedigree intact? The cloud colour This gene’s one epigenetic value, drawn on the allele copy and inherited with it, held to a bright saturation and value like every other rolled colour in the mod — a faint cloud round a wolf at night is the whole visual, and one that rolled a muddy olive would read as a bug rather than as variety. It is also the only heritable thing about a shifted animal, which makes it the only thing to breed for once you have the shape: a line of were-cats can be bred toward a particular colour of cat. What lives where The gene owns the genetics and the cloud colour and nothing else; the shift is hand-written behaviour in the game module. That is the same split sun sensitivity makes, for the same reason: each of these would be an effects verb with exactly one user, and the effects vocabulary is meant to be things a data-driven gene would reach for. LycanthropyHandler.isWearable is the second half, and the one that will matter when the roster is derived from the live registry: at dusk the resolved entity type is asked whether it swims (the four water spawn categories), flies ( AMBIENT , FlyingAnimal , a FlyingPathNavigation or a FlyingMoveControl ) or is hostile ( Enemy or MONSTER , through MobGroups.isHostile ) or is hurt by water ( isSensitiveToWater() , since 2026-10-09 ), and a body that fails refuses the shift and logs once. AMBIENT is in the flying list because vanilla's bat flies without a flying navigation or the interface to show for it — unverified in game, and the safe direction to be wrong in. Chaos: one allele for every modded mob (2026-10-01) Asked for out of intake/ as “rebuild the roster from the live registry”, and built the other way round on purpose. An allele per registry entry was rejected after reading the code: a token is text in the genotype code and registry ids collide with its separators; a live-registry allele list changes with the modpack, so two servers would read one code differently; and the designer, the census and this wiki are baked from common/ , where no registry exists. So the vanilla forms are untouched and the locus gained one allele, Cha , between Wlf and n (every existing pair sorts as before; tokens, not orders, are stored). The value is on the copy. Each Chaos copy carries a SEED epigenetic value named chaos ( MobRoster.CHAOS_SEED ), beside the cloud colour. LycanGene.chaosSeed(pair, epigenetics) returns it only when the pair is Cha/Cha and both copies carry the same seed — the matched-pair rule, one level down. Founders share it. Two independently rolled seeds never match, which would have made every wild Chaos founder the mismatched outcome. A new Gene.foundersShareSeeds() names seed values a freshly made horse carries identically on both copies; Epigenome applies it wherever it rolls two copies together (the founder roll, copiesFor , and alignedTo filling an empty pair). Breeding never applies it, so two lines crossed stay two lines. LycanGeneTest pins both, and fails when the sharing is removed. The game resolves it. ChaosRoster takes every entity type that is not minecraft: or ours, can be summoned, is not excluded by the chaos.exclude_mods / chaos.exclude_ids server config, and builds into a non-horse Mob ; sorts by id; and keeps, for this locus, the ones isWearable accepts — the very check the shift makes at dusk, so the two cannot disagree. The seed picks floorMod(seed, size) . Built lazily on the first Chaos lookup, rebuilt only when the exclude lists change; a type that throws while being built is skipped and logged once. Weighted as one form in the founder table ( 0.03% , homozygous), and kept there in a pack with no modded mobs, so a code means the same thing everywhere. Checked by the chaos_roster gametest (the classifier on vanilla wolf, bat, cod, bee, zombie, horse and arrow; the real lists sorted, never vanilla or ours, stable, and nested lycan pack spawner), which passed on 2026-10-01 with all three modded lists empty, since the dev run has no other mod with mobs in it.
