Config
(Built / the sweep still planned)
What a server owner or a single player may turn down, turn off or retune without touching the code. Every key the mod reads is listed on the Gameplay tab, baked from the config classes themselves, with its default, what it accepts, the comment the file carries, and the page of the feature it governs. The surface grew an option at a time wherever one was needed; the Roadmap tab is the sweep that would give it a shape, and the place the refusals live — there are things that look like config and cannot be, and the genetics are the sharpest of them.

How the table is made wiki/tools/bake-config-keys.mjs reads the four classes — ServerConfig , ClientConfig , BreedSpawningConfig and carts/CartsConfig — and rewrites the span between the BEGIN / END generated config keys comments on this page. --check exits 1 instead when the span is stale. It is row y of procedures/rebake.txt , and step 9 of add-a-config-option runs it. It reads the Java source, the way the builder does. A comment() waits for the next define* call, or for a push() , which takes it as the section’s comment; push and pop build the dotted key. A key with no comment of its own — the four per-breed keys — takes its line from the enclosing section’s comment, where BreedSpawningConfig describes each one. A default that names a constant is read from the constant , in the same file or in common/ ( ReproRules.DEFAULT_NATURAL_CAP ), so the table cannot disagree with the game about a number. An enum key’s allowed values are the enum’s constants. The few defaults that are not constants — !production() , a breed’s own weight — are words in the script’s PLACEHOLDERS . Loops are written once, as a template. One section per shipped breed and one per CartKind are listed as breeds.<breed id>.* and carts.<cart id>.* , not once per breed: the breed’s own file is what fills them in. It fails rather than write a short table. Every .define*( in each builder must become a row; every key needs an entry in the script’s HOME map (its feature page, the one hand-written thing in it), every HOME entry must name a live key and an anchor that exists; a default it cannot evaluate is an error, not a blank cell. Reading source rather than booting a game and walking the built ModConfigSpec was a choice of cost: the NeoForge module’s test classpath carries no Minecraft on purpose, and a bake that needs a server boot would be run less often than one that takes a second. The price is that a builder written in a shape the script has never seen fails it, which is the safe direction.
