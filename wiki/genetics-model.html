The genetics model

Alleles are objects, not letters in a string. A horse carries one AllelePair per registered Gene, plus an epigenome — a priority and a random seed riding on each allele copy. Everything below lives in common/genetics/ and imports nothing from Minecraft.

The pieces

TypeWhat it is
GeneAn interface: the alleles a locus defines, how they segregate, and how the locus changes the coat. One singleton instance per gene.
AlleleOne allele of one gene. Identified by <modauthor>.<gene>.<token>, e.g. horsegenetics.splash.Spl.
AllelePairThe two copies a horse carries at one gene. A record, canonicalized dominant-first on construction.
GenotypeOne AllelePair per registered gene. Round-trips through a code string.
AlleleEpigenetics(int priority, long epigeneticSeed) — the heritable payload on one copy of one allele.
EpigenomeOne AlleleEpigenetics per copy, aligned slot-for-slot with the genotype’s pairs.
GenomeGenotype + Epigenome. The thing a foal actually inherits.
GenesThe registry. Three orderings: codeOrder(), naturalOrder(), magicalOrder().
DominancePatternPer-gene metadata: DOMINANT / RECESSIVE / INCOMPLETE_DOMINANT / COMPLETE_DOMINANT.
GenotypeCatalogEvery visually distinct genotype the registry can produce, in a stable order.
GeneSpec / SpecGeneA gene described as a JSON file rather than a class, and the Gene that answers everything from it. Indistinguishable from a hand-written gene everywhere below this table.

The genotype code string

A Genotype serialises to one segment per gene, in Genes.codeOrder(). Segments are joined by -, the two alleles of a gene by /, dominant first:

E/e-A/a-w/w-t/t-c/c-Spl/spl-g/g-Cr/N-N/N-Mzeb/n-n/Pihr

 |   |   |   |   |    |      |    |    |    magic zebra

 |   |   |   |   |    |      |    cream

 |   |   white

Allele tokens can be any run of characters — Spl, Cr, prl, Mzeb, Pihr — not single letters. The / and - separators keep that unambiguous. The forward-looking rule for third-party genes is stricter: alphanumeric tokens, 1–128 characters, wild type named n.

No legacy handling

Genotype.parse requires exactly one segment per registered gene. There is no padding, no short-code fallback and no version field — when the format changes it changes, and old saves are discarded. That rule was written for a solo developer; what happens when a player installs a gene mod is still an open question.

Dominance as declared metadata

Gene.dominance() does not do the expressing — restrict and tint do that. It tells the rest of the mod what to expect, so code can reason about a gene without special-casing it by key. Every gene declares it.

PatternMeaningDistinct pairs
DOMINANTOne variant allele gives the full effect; the heterozygote is the homozygous variant.2 (both homozygotes)
RECESSIVEOnly the homozygous variant shows; the heterozygote is an invisible carrier.2 (both homozygotes)
INCOMPLETE_DOMINANTThe heterozygote has a look of its own, between the two homozygotes.3 (all pairs)
COMPLETE_DOMINANTDominant and epistatic: while the variant shows, no other gene is visible.1 (the variant, on wild type)

Two questions callers ask: heterozygoteIsDistinct() (only INCOMPLETE_DOMINANT) and masksOtherGenes() (only COMPLETE_DOMINANT). Today the one consumer is GenotypeCatalog; the obvious next ones are a punnett / expected-foal display and “carrier of X” wording in the info panel.

Epigenetics ride on the allele, not on the horse

A genotype says which alleles a horse carries. It does not say what those particular copies are carrying, and every copy carries two things:

  • a priority — an int in [1, Integer.MAX_VALUE];
  • an epigenetic seed — the long that drives that gene’s per-horse randomness (bay point heights, grey dapples, splash markings, zebra stripe knobs).

So a horse carrying A/a has a seed on its A and another on its a, and a foal that inherits the A inherits that copy’s seed exactly — no re-roll, no jitter. Bay point heights run in families rather than being reinvented every generation.

Which copy expresses

CaseExpressed copy
HeterozygoteThe dominant copy — AllelePair is canonicalized dominant-first, so it is first().
HomozygoteBoth copies express, so the tie goes to the higher priority.

That is what Epigenome.expressed(gene, genotype) answers, and its seed is what CoatBuildContext.epigeneticsFor(geneKey) runs on.

Priority selects a seed, never an order

Epigenetic priority picks which copy’s seed expresses. It can never move a gene in the processing queue, and by design it never will — if it could, two horses with the same genotype and the same seeds could diverge on priority alone and silently share a coat cache entry. Gene processing order is a separate, hard-coded, per-gene number. See Philosophy §2 and Roadmap §2.

The epigenome code string

Same shape as the genotype code: one segment per gene in codeOrder(), joined by -, the two copies joined by /, each copy written <priority>:<seed hex>. 

17334:9f3c1ab27de40015/842911:0c5e...-...-...

Epigenome.fromSeed(long) replays a whole epigenome from a single long, which is the stand-in FamilyTreeScreen uses for an ancestor whose real epigenome is not stored anywhere — a plausible pattern, not necessarily the real one.

Founders roll; foals inherit

  • Founder (wild spawn, /summon, a gallery horse) — Epigenome.random(rng): an independent priority and seed on every copy, deconflicted. Reached through CoatGenerator.generate, which is the founder path.
  • Foal — Genome.breedWith. Every inherited allele brings its parent copy’s priority and seed verbatim. A foal must never go through the founder path.

If both copies arrive on the same priority, one extra nextBoolean() bumps the second ±1 (AlleleEpigenetics.deconflict), clamped to [1, MAX] — so a horse never carries a tie. Full inheritance detail is on the breeding page.

What the texture key captures

CoatData.textureKey() is the genotype code, plus @<fingerprint hex> only when the horse is non-deterministic. Epigenome.visibleFingerprint(genotype) digests only the expressed seeds of genes that are both visible and non-deterministic, so epigenetics a horse cannot show do not fork the cache.

common/genetics/Genotype.java — the two questions the cache asks
/** Is every gene's contribution identical on every horse with this genotype? */
public boolean isDeterministic();

/** Does any *visible* gene need per-horse randomness? -> bake per horse. */
public boolean hasVisibleNonDeterministic();

Gene.isVisible(pair, genotype) and Gene.isDeterministic(pair, genotype) both see the whole genotype, which is how agouti knows it is invisible on a chestnut and how cream and pearl read each other.

Declare determinism honestly

Claiming determinism you do not have poisons the coat cache for every horse sharing your genotype: the first horse to bake wins, and the others render its coat. This is the single most damaging mistake a third-party gene can make.

The genotype catalogue

GenotypeCatalog enumerates every visually distinct genotype the registry can produce. Nothing is hard-coded — it falls out of codeOrder(), each gene’s allele list and each gene’s dominance, so registering a gene widens it on its own — the catalogue is built lazily and thrown away whenever the registry changes, which is what makes a drop-in gene show up in the gallery without anything else being told about it.

allPairsOf(gene)Every unordered pair, least dominant first (ee, Ee, EE).
distinctPairsOf(gene)The same, with the dominance reduction applied.
totalGenotypes()The raw product — 177,147 at 11 genes.
size()The reduced catalogue — 1,730.
get(i) / entries()Read the list, built once at class load.

The arithmetic: 2·2·2·3·2·3·3·2·2 = 1,728 unmasked, plus one white pen and one test pen (each COMPLETE_DOMINANT gene collapses to a single entry) = 1,730. Ordering is a mixed-radix odometer whose first gene is the fastest-varying digit, so the catalogue reads eeaa, EEaa, eeAA, EEAA, [white], [test], eeaa ChCh, …

Its only consumer today is the horse dimension’s gallery, which is slated to revert to random pens — the catalogue itself stays, because a punnett display and the tests want it.

Phenotype, coarsely

Genotype.phenotype() gives a coarse CoatPhenotype (CHESTNUT / BLACK / BAY / WHITE; everything else ignored). It is only a family-tree fallback now — foals and adults alike are fully generated through the coat pipeline.
