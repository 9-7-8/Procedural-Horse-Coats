Magical gene / phase 3

Pink hair

The mane and tail turn pink — and keep their shading, because the gene reads what each hair texel currently looks like before deciding what to add. It is also the mod’s clearest carrier locus: a single copy is a carrier you cannot see, so it is the first thing you have to breed for rather than spot.

Sample bakes look right — pink manes keep their strand shading on black, chestnut and perlino alike. Nothing has been seen in-game; the checklist is on To be verified.

It reads before it writes

Flat paint would throw away the shading the natural phase gave those strands and leave a dead pink slab. So the gene asks ColorView.visible what each hair texel currently looks like, and returns the delta that walks it 82% of the way to hot pink.

common/genetics/genes/PinkHairGene.java
/** The signed step from this texel's accumulated channel to its pink one. */
private static int toward(ColorView colour, int px, int py, int channel, int target) {
    int seen   = colour.visible(px, py, channel);
    int wanted = (int) Math.round(seen + (target - seen) * (STRENGTH_PERCENT / 100.0));
    return wanted - switch (channel) {
        case 0 -> colour.red(px, py);
        case 1 -> colour.green(px, py);
        default -> colour.blue(px, py);
    };
}

The mane keeps its own light and dark while ending up unmistakably pink on a black, a chestnut or a cremello alike. It also raises opacity, so a dominant-white horse gets pink hair rather than nothing.

A blind add cannot do this — and that is the point

To reach pink on a black mane, a fixed delta has to push so hard that a pale mane saturates to white. Reading first is exactly what phase-3 read access exists for.

The cost is that this gene is order-dependent by choice, which is why it runs before magic zebra in Genes.magicalOrder(): stripes should black out pink hair, not the other way round.

Why a carrier gene, and why 1 in 12

Every other gene in the mod is spottable — you can look at a horse and know whether it has the thing. Pink hair is the first where the carrier is invisible, so finding one is a breeding problem: you notice one wild horse in 144 showing it, and you have to work out who else is carrying.

The comparatively common allele frequency is deliberate for that reason — an invisible carrier that is also rare is something nobody ever gets to play with. At 1 in 12 per allele, roughly 16% of wild horses carry a copy.

It also makes pink hair the natural first consumer of a “carrier of X” display: the gene declares a pink-carrier wild-type expression with its own description, so the wording a UI would show already exists — nothing reads it yet but the gene dictionary.

Foals get a pink tail only

The foal mesh has no MANE part (see body space), so the gene skips it. The mane arrives with adulthood. The loop guards with hasPart, which is the pattern every part-targeted gene should copy: 

private static final List<Part> HAIR = List.of(Part.MANE, Part.TAIL);

for (Part part : HAIR) {
    if (!HorseSkinGeometry.hasPart(skin, part)) {
        continue;                                   // a foal has no mane
    }
    HorseSkinGeometry.forEachTexel(skin, part, (px, py, p, face, point) -> {
        delta.add(px, py,
                toward(colour, px, py, 0, PINK_R),
                toward(colour, px, py, 1, PINK_G),
                toward(colour, px, py, 2, PINK_B));
        delta.addOpacity(px, py, 255 - colour.opacity(px, py));
    });
}

One more thing about the allele order

alleles() declares List.of(n, Pihr) — the baseline first. That order is bookkeeping, not biology: it only fixes which allele lands in which slot of an AllelePair, so a pair equals its reverse and the code string round-trips. Nothing about what the combination does consults it. A horse’s code segment reads n/Pihr for a carrier and Pihr/Pihr for an affected horse.

Not modelled yet

One intensity, no per-horse variation. Alleles for a couple of intensities are the obvious extension — and would make it the first magical gene with a real allelic series.
