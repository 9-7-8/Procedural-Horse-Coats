intake/Sizing.txt - the sizing of every unit in intake/, so process-intake need not re-read
every treatment each run. NOT a treatment and NOT a unit: never build from it, never count it.

How to use it (process-intake step 1):
- Trust a row only while its treatment is unchanged since the date at the top of its block:
  `git log --since=<date>T00:00 --oneline -- "intake/<file>"` empty -> the row stands.
  (The T00:00 matters: a bare date counts from the current time of day.)
- A treatment changed since, or a new one -> re-size that file alone, and rewrite its block.
- A unit shipped -> delete its row in the same change that retires it from the treatment.
- A treatment deleted -> delete its block.
Size: S = one screen or class + one test class; M = one session; L = several sessions, or a
foundation others wait on. Impact: a finishes shipped work, b unblocks units, c new content.
"Owner" = No when it has an Open: design call, says "confirm with the owner", designs a breed,
or touches wiki/philosophy.html. "Built?" is a grep of the code and wiki/text on that date.
