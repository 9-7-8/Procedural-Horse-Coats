"PNG - Pixel Art Textures" - source, licence, credit

What it is
==========
About a thousand block-style pixel-art texture tiles as PNGs, in folders under
PNGs/: Bricks, Concrete, Debris, Decorations, Dirt, Doors, Fabric, Foliage,
Glass, Grass, Gravel, Metal, Paper, Patterns, Pebbles, Rockface, Roofing, Sand,
Snow, Stones, Tiles, Wall, Water, Windows, Wood. Files as received in
"PNG - Pixel Art Textures.zip", unmodified.

Redistribution here - READ THIS
===============================
Keeping the whole pack in intake/ of a public GitHub repository is publishing it
as a standalone collection, which the last sentence above forbids, even though
intake/ is not in the jar. The files in this folder are therefore NOT committed
to git as of the session that filed them (only this notice and USAGE.txt are),
pending the owner's decision. If you want the pack kept in the repo anyway, that
is the owner's call and a knowing exception to the licence; the safe route is to
keep the zip outside the repository and copy only the tiles the mod really uses
into a module.
