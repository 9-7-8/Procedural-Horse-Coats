What is actually in the 64x64 zip (opened 2026-09-29)
=====================================================
  zip sha256   5364f868d5f436c7c733ff9a369cc129987b85b026b895a3bd4bc33aab375d7a
               ("Pixelated Patterns 64x64.zip", 183 kB, one folder
                "Pixelated Patterns 64x64/", unzipped here as 64x64/)
  125 PNGs, no licence file, no readme, nothing else in the zip.
  EVERY file is 64 x 64, 8-bit RGBA (PNG colour type 6). None is greyscale as
  stored, so a mesh base wants a channel pulled out rather than the file as-is.

Twenty pattern families, each in five colourways - Black, Blue, Green, Red,
White - and some in two numbered variants:
  Bricks (x2)        Camouflage         Caustics           Cobblestone (x2)
  Cracked_Bricks     Cracks (x2)        Crate              Crystals
  Diagonal_Tiles     Metal (x2)         Metal_Floor        Rocky (x2)
  Smoke              Stone              Tiles              Wavy
  Weaving            Wood               Wood_Planks (x2)

Two filenames are the author's slips, not ours, and a loader that parses names
has to cope with both:
  Caustics_Green.png     - missing the "_64" suffix every other file carries.
  Metal_Greeb_2_64.png   - "Greeb" for "Green". It is the Metal family's missing
                           green variant 2 (Metal_Green_2_64.png does not exist).

Licence - STILL NOT STATED, after reading the store page
========================================================
The page was fetched again on 2026-09-29 and it carries NO licence section, no
terms, no credit request, and the zip contains no licence file either. The only
rights-adjacent text on the page is two itch.io tags:
    "Royalty Free"
    "No generative AI was used."
A tag is not a grant. "Royalty free" says no per-use fee; it says nothing about
redistribution, which is the clause this repo needs, because anything used ships
inside the jar and the mod's own CC BY-NC licence lets forks redistribute in
turn. So, unchanged:
  - treat as all rights reserved by NormalMap_Games;
  - do NOT commit the images to git (the .gitignore rule for this folder keeps
    them out, the same way as the Raven icons);
  - do NOT copy anything into a module.
TO SETTLE IT the owner needs to ask NormalMap_Games directly (itch.io page
comments or the profile's contact) whether the textures may be redistributed
inside a free, open-source mod, modified, under a CC BY-NC project, and what
credit they want. Paste the reply here verbatim. If it permits redistribution,
relax the .gitignore rule and say so here.
