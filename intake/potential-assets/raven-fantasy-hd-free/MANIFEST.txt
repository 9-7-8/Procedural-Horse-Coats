folder (intake/potential-assets/raven-fantasy-hd-free/):

  RAVEN FANTASY HD ULTIMATE FREE/Separated Files/FHD (1).png ... FHD (806).png

Where to get them again
  https://clockworkraven.itch.io/raven-fantasy-hd-ultimate-rpg-icons-pixel-art-icons-textures-and-sprites
  Download "RFHD Free Files.zip" (1.1 MB, the free one). A session that needs these
  images and does not find them should PROMPT THE OWNER with this link, not try to
  fetch them itself (itch.io is behind the sandbox's network policy).

How to handle it on the machine
  - Unzip the free zip into this folder. Git will not see the images: the repo's
    .gitignore ignores this folder's contents except the notes. If `git status`
    ever lists any of them, a pattern is wrong: fix .gitignore, never `git add`
    around it, and never `git add -f`.
  - A session that finds the images absent should NOT treat that as a bug and
    should not try to fetch them (the store is behind a login/payment flow and
    the sandbox cannot reach it). Ask the owner, or work without them.
  - When something is used, copy that ONE file into the module that needs it,
    log it in USAGE.txt, and follow "What this means for the mod" in
    SOURCE-AND-LICENSE.txt (notice + carve-out + credit).
