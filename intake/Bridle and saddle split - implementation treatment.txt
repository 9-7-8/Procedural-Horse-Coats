Bridle and saddle split - implementation treatment

Scoped with the owner in a cloud session (intake only: no code, wiki or asset changed). Every
"Decided" line is her call; "Recommended" lines are mine, not asked; "Open" lines still need an
answer, by whom is on the line; "UNVERIFIED" lines are facts this file has not proved. Source of
truth for what exists: wiki/horse-gear.html (Gameplay and Coding tabs, read as wiki/text/
horse-gear.*.txt) and wiki/philosophy.html ("utility, not decoration"). This file is retired
(deleted, per /process-intake step 8) when it ships and moves onto horse-gear's Gameplay and
Coding tabs. Second round of questions answered 2026-10-02; the Open list is now short.
Release: patch (Decided), and the note says saddles are now bridles.

1. The ask, in one paragraph
============================
Split what the vanilla saddle does today (it both lets you sit on a horse and lets you steer it)
into two pieces of tack. A BRIDLE steers. A SADDLE is a new item of this mod's own that carries
stats. Below the top bond tier a horse that wears a saddle and no bridle can be ridden as a
passenger but not steered.

2. What already exists (read from wiki/text/horse-gear.*.txt on 2026-10-02)
==========================================================================
- Nineteen gear slots; two are real vanilla EquipmentSlots (SADDLE and BODY) and seventeen are a
  data attachment (HorseGear). A foal wears nothing.
- The slot roster is entity/HorseTackSlot. The Head zone has one slot, Headstall, documented as
  "A bridle or a halter - one or the other, never both"; the Body zone has Pad, Saddle, Barding,
  Blanket. Slot tags (horsegenetics:gear/<slot>) decide what a slot accepts; fifteen are empty.
- Today the Saddle slot is the vanilla one and takes the vanilla saddle. Hold a piece of gear and
  right-click the horse and it goes into the first empty slot that takes it (rider comfort).
- Gear must do something: "Cosmetic-only equipment is the thing this mod does not add", and tack
  carries real effects (philosophy, utility not decoration; that call reversed an earlier "tack
  gets no stats").
- A Tack Dyeing Bench already dyes tack; the saddle has a dye zone called "Bridle" today
  (UNVERIFIED which zones: read the Tack Dyeing Bench page and the saddle item).
- Bond tiers live on wiki/horse-care.html; the bond tier that counts as "tier 3" is read from
  there, not from this file (UNVERIFIED which constant names it).

3. Decided (owner, all asked)
=============================
Rules
- Bridle worn in HEADSTALL (shares it with the halter). The SADDLE slot is for the mod's own new
  saddle item, a second piece beside the bridle.
- The bridle IS the vanilla saddle item: it KEEPS the id minecraft:saddle, renamed and retextured.
  Every saddle in old worlds, loot, trades and other mods therefore reads as a bridle.
- Bridle alone: you can mount and steer (no saddle needed).
- Saddle alone, below bond tier 3: passenger only, cannot steer.
- Nothing worn, below tier 3: you can mount as a passenger (no steering).
- Bond tier 3 and up: the horse steers freely with or without a bridle (existing bareback rule).
- A passenger-only horse walks on its own, herd-like (reuse existing herd AI), carrying you.
- Horses only: donkeys, mules and llamas keep vanilla saddle behaviour.
Saddle
- Stats: SPEED and JUMP, plus CARRY CAPACITY / saddlebags.
- Stats apply ONLY WHILE RIDDEN and are not shown on the horse's own genes/stat screen.
- Source: crafted, with material tiers (stats scale by tier).
Bridle
- Crafted from leather plus iron or string; dyed at the Tack Bench; the saddle's old "Bridle" dye
  zone moves to the bridle item, so bench dyes bridle and saddle separately.
Config
- One SERVER boolean, default ON, to turn the passenger-only rule off and restore "a saddle
  steers" (add-a-config-option).
Release
- Patch release, noted. Ships per piece. No compat bump: the id is kept, so no saved stack is
  rewritten (see 5, one exception).

4. Contradictions to settle in the build (not owner questions)
=============================================================
- "Bridle alone mounts and steers" together with "nothing worn mounts as a passenger" means vanilla's
  requirement of a saddle to ride is gone for horses. UNVERIFIED how vanilla 26.1.2 lets a
  tamed unsaddled horse be mounted and who controls it (AbstractHorse.getControllingPassenger
  hands control only if isSaddled()). Read the sources first.
- Vanilla steering reads the vanilla SADDLE slot, but the bridle now lives in Headstall. The
  existing BarebackSteeringHandler already lends a hidden "phantom saddle" (PHANTOM_SADDLE data
  component, never drawn, taken back each tick) so vanilla's steering path runs. Recommended:
  extend that handler so a bridle in Headstall (or tier 3) is also a reason to lend it, and so
  the real saddle's presence no longer implies steering. One mechanism, not a second path.
- The vanilla saddle item is equip-on-interact into the SADDLE slot (Equippable.saddle). A
  bridle-in-Headstall needs that click redirected to Headstall for horses, while donkeys keep the
  vanilla slot. UNVERIFIED how to intercept; TackEquipHandler skips vanilla slots on purpose.
- Existing saddled horses: their old saddle sits in the SADDLE slot and must be moved into
  Headstall once on load (flagged), otherwise it would become a "saddle" that no longer steers.
  This is a data move, so hard rule 10 asks for a migration even though the item id is kept.
- Our new saddle needs its own item id (the vanilla id is the bridle).
- Rider-only stats must be read where the rider is known, not from the horse's attributes; the
  genes screen must not show them. Pad and saddlebag slots interact (bags: capacity from the
  saddle).

5. Saves
========
Item id kept, so inventories and loot are unchanged. One migration: a horse that wears an
old-style saddle in the SADDLE slot moves it to Headstall once. A horse that has that gear while
the mod is removed is vanilla-saddled again. Defect to test: a world saved before the update,
loaded after, with a ridden saddled horse.

6. Where it touches
===================
Genetics, coat, breeds, pedigree: untouched. Gear (HorseTackSlot, tags, Gear tab hints):
touches. Items and crafting: touches (bridle recipe, new saddle item and tiers, lang,
textures, dye zones). Riding/steering/bond: touches. Multiplayer: server decides steering.
Config: one server key. Other mods: touches (their saddles read as bridles; carts and second
seats UNVERIFIED). Wiki: horse-gear both tabs, Tack Dyeing Bench, rider-comfort, a page per new
item. Tests: a common/ rule class for "who steers" pinned by unit tests; gametests for bridle-only,
saddle-only, nothing-worn below tier 3 and tier 3 bare, plus the migration.

7. Order and size
=================
1. Bridle: relabel and retexture the vanilla saddle, move it to Headstall, migrate old worlds,
   dye zone (M; the click redirect and migration are the work).
2. Passenger-only rule below tier 3, the server switch, herd-like carrying (M).
3. The mod's saddle: tiers, rider-only speed/jump, bags (M-L). Each ships alone, in this order.
